#### ResMed firmware repository

- Store firmware images on the SD card, organize them in directories
  and install them directly from the repository or from a local file.
- Dump the current device firmware to SD.

#### Web UI

- English and Polish, selected automatically from the browser language.
- Light and dark themes, with automatic or manual selection.
- mDNS support (airbridge.local).

#### AirBridge updates

- Allow installing from HTTP/HTTPS URL.
- Update notices and release notes are available in the Web UI.

#### Fixes and improvements

- Faster chart preparation and more reliable recovery from interrupted
  report generation. 
- Fixed repeated report reindexing. Cleanup no longer gets stuck on
  empty SD cards.
- Improved backward clock synchronization on devices that reject a normal
  time change.
